# Pilotéo — Manuel utilisateur

Bienvenue dans Pilotéo, l'outil de suivi des affaires, du temps, des frais et
de la facturation de votre cabinet.

Ce manuel s'adresse à tous les utilisateurs de Pilotéo : consultants,
pilotes d'affaires et administrateurs de cabinet. Il ne suppose aucune
connaissance informatique particulière.

## À quoi sert Pilotéo ?

Pilotéo vous permet de :

- **saisir votre temps** : missions, activités internes, absences ;
- **saisir vos frais** et suivre vos notes de frais jusqu'à leur remboursement ;
- **consulter vos affaires et vos missions** ;
- **piloter vos propres affaires** si vous en avez la responsabilité : suivi du
  budget, des missions, des alertes de facturation ;
- pour un administrateur : gérer les consultants, les référentiels du
  cabinet, la facturation et les données de la société.

Chacun ne voit et ne modifie que ce qui le concerne. Un consultant ne voit
jamais les temps, les frais ou le TJM d'un collègue.

## Les trois façons de démarrer

Au tout premier lancement de Pilotéo, on vous propose un choix. Il n'y a pas
de mauvaise réponse : vous pourrez toujours évoluer plus tard.

### 🖥️ « Mes données restent sur cet appareil »

Vous travaillez **seul**, sans compte, sans connexion internet obligatoire.
Vos données restent uniquement sur cet ordinateur ou cette tablette. C'est le
mode le plus simple pour démarrer immédiatement, par exemple pour tester
Pilotéo ou pour un usage strictement personnel.

### 👥 « Créer un espace pour mon équipe »

Vous créez un espace de travail partagé pour votre cabinet ou votre équipe.
Vous vous connectez avec un compte Google, vous donnez un nom à votre
organisation, et vous choisissez où seront rangées les données partagées
(dans votre Google Drive, par exemple). Vous devenez alors le premier membre
avec le rôle **propriétaire de l'espace**, et vous pouvez inviter vos
collègues. Un essai gratuit de 20 jours démarre automatiquement — voir
[04-licence-et-essai.md](04-licence-et-essai.md).

### ✉️ « J'ai reçu une invitation »

Un collègue vous a invité à rejoindre l'espace de son cabinet. Vous vous
connectez avec le compte Google attendu, vous saisissez ou scannez le code
d'invitation reçu, et vous accédez aux données selon les droits qui vous ont
été accordés.

## Solo ou équipe : la différence en un coup d'œil

| | Mode solo | Mode équipe |
|---|---|---|
| Compte requis | Non | Oui (compte Google) |
| Où sont les données | Uniquement sur votre appareil | Sur votre appareil, synchronisées avec vos collègues via l'espace de stockage choisi par l'organisation |
| Fonctionne hors connexion | Oui, toujours | Oui, puis se resynchronise dès le retour du réseau |
| Plusieurs personnes | Non | Oui, avec des rôles différents pour chacun |
| Coût | Gratuit | Essai de 20 jours, puis licence |
| Peut évoluer | Peut rejoindre une équipe plus tard | — |

Vous pouvez très bien utiliser Pilotéo à la fois pour votre activité
personnelle en solo **et** faire partie d'un ou plusieurs espaces d'équipe
depuis la même application — voir [03-equipe-et-synchro.md](03-equipe-et-synchro.md).
